# Разминка рук в написании FrontEnd для сайта

### Описание:
Задача включает разминку и практику в разработке FrontEnd для веб-сайта. Исследуются базовые технологии, такие как HTML, CSS, для создания интерактивных и визуально привлекательных интерфейсов. Это помогает освежить навыки верстки и взаимодействия с пользовательским интерфейсом перед более сложными проектами.

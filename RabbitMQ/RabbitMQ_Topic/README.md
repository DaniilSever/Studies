### Задача:
* Изучение RabbitMQ маршрутизация тип "Topic Exchange"

### Описание:
Задача включает изучение маршрутизации сообщений в RabbitMQ с использованием типа "Topic Exchange". Изучаются принципы маршрутизации с помощью шаблонов тем, что позволяет гибко направлять сообщения в зависимости от конкретных паттернов в ключах маршрутизации. Это помогает настроить более сложные и гибкие механизмы распределения сообщений между различными потребителями.

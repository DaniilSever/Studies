### Задача:
* Изучение RabbitMQ маршрутизация тип "Fanout Exchange"

### Описание:
Задача включает изучение маршрутизации сообщений в RabbitMQ с использованием типа "Fanout Exchange". Изучаются особенности отправки сообщений во все связанные очереди без учета ключа маршрутизации, что полезно для реализации широковещательной передачи данных. Это помогает понять, как организовать распределение сообщений между множеством потребителей.

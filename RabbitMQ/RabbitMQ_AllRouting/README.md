### Задача:
* Изучение RabbitMQ в одном проекте объединить все типы маршрутизации

### Описание:
Задача включает изучение интеграции всех типов маршрутизации RabbitMQ (Direct, Fanout, Topic, и DeadLetterExchange) в одном проекте. Осваиваются принципы комбинирования различных типов обменников для реализации сложных сценариев маршрутизации и обработки сообщений, включая управление ошибками и масштабируемость. Это помогает создать универсальное решение для гибкого и надежного обмена сообщениями в распределенных системах.

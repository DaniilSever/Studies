### Задача:
* Изучение работы с RabbitMQ в Docker

### Описание:
Задача включает изучение работы с RabbitMQ в контейнерах Docker для упрощения развертывания и управления сервисами обмена сообщениями. Осваиваются основы создания и конфигурации RabbitMQ-контейнеров, а также интеграция с другими сервисами внутри Docker-сети. Это помогает эффективно использовать RabbitMQ в изолированных и масштабируемых окружениях.

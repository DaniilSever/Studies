# Обучение по использованию RabbitMQ

### Описание
Задача включает обучение работе с RabbitMQ — системой обмена сообщениями, основанной на очередях. Изучаются основные концепции, такие как создание очередей, обменников, подписчиков и настройка обработки сообщений. Это помогает освоить инструмент для организации взаимодействия между сервисами в распределенных системах.

### Задачи
- Изучить работу с RabbitMQ в Docker
- Изучить типы маршрутизации Header Topic Fanout
- Попробовать объединить Direct, Fanout, Topic маршрутизации в 1 проект.
- Изучение типа маршрутизации DeadLetterExchang
- ...

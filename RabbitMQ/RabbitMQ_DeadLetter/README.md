### Задача:
* Изучение RabbitMQ маршрутизация тип "DeadLetterExchange"

### Описание:
Задача включает изучение маршрутизации сообщений в RabbitMQ с использованием типа "DeadLetterExchange" (DLX). Осваиваются механизмы перенаправления сообщений, которые не могут быть обработаны, в отдельную очередь для дальнейшего анализа или повторной попытки. Это помогает эффективно управлять ошибками и гарантировать надежность обработки сообщений в распределенных системах.


## Задание:
Пользователь зашел через JivoChat на сайте. Ему создалась очередь для общения.

Второй зашел через телеграм-бота и тоже написал обращение.

Оператор поддержки обслужил оба обращения. И написал ответы. Но пользователь ушел с сайта и не прочитал. 

Нужно это сообщение убить и увидев, что он не получил - отправить на почту. (Пользователь на сайте оставил почту)

### Задача:
* Изучение работы с Kafka в Docker

### Описание:
Задача включала изучение работы с Apache Kafka в среде Docker. Были настроены и запущены контейнеры для Kafka и Zookeeper, а также проведены базовые операции по созданию топиков, отправке и чтению сообщений. Это позволило понять основы работы с Kafka в изолированной среде для дальнейшего использования в проектах.

# Изучение работы типа Protocol и отображение его ошибок в линтере mypy

### Описание:
Задача включает изучение работы с типом **Protocol** в Python, который используется для определения структурных подтипов (утиной типизации). Исследуется, как создавать и использовать Protocol для описания интерфейсов, а также как mypy, статический анализатор типов, проверяет соответствие кода этим интерфейсам и отображает ошибки. Это помогает улучшить качество кода за счет строгой проверки типов.

# Изучение работы с LinkedList

### Описание:
Задача включает изучение работы с LinkedList — структурой данных, основанной на элементах, которые содержат ссылки на следующие элементы. Осваиваются операции добавления, удаления и поиска элементов, а также манипуляции с указателями для эффективного управления памятью. Это помогает понять основы работы с динамическими структурами данных и их использование в различных алгоритмах.

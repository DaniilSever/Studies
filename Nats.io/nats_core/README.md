# Обучение по использованию nats core

### Описание:
Задача включает изучение работы с NATS Core — высокопроизводительной системой обмена сообщениями. Исследуются основные функции, такие как публикация и подписка на сообщения, а также настройка и запуск NATS-сервера. Это помогает понять принципы работы с messaging-системами и их применение в микросервисной архитектуре.

### Задачи:
- Изучить паттерн Publish Subscribe
- Изучить паттерн Queue Groups
- Изучить паттерн Request-Reply

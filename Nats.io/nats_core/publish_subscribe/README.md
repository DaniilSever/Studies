### Задача:
* Изучение паттерна Publish Subscribe

### Описание:
Задача включает изучение паттерна Publish-Subscribe (Pub/Sub) для обмена сообщениями между компонентами системы. Исследуются основные принципы работы: публикация сообщений в топики и их подписка для получения данных. Это помогает понять, как эффективно организовывать взаимодействие в распределенных системах и микросервисных архитектурах.

### Задача:
* Изучение паттерна Request-Reply

### Описание:
Задача включает изучение паттерна Request-Reply, используемого для организации синхронного взаимодействия между компонентами системы. Исследуется, как клиент отправляет запрос (request) и ожидает ответа (reply) от сервера, обеспечивая двустороннюю коммуникацию. Это помогает понять принципы работы с синхронными сообщениями и их применение в микросервисных архитектурах.

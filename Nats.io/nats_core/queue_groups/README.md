### Задача:
* Изучение паттерна Queue Groups

### Описание:
Задача включает изучение паттерна Queue Groups, используемого в messaging-системах для распределения нагрузки между потребителями. Исследуется, как группа подписчиков может совместно обрабатывать сообщения из одного топика, обеспечивая балансировку и отказоустойчивость. Это помогает понять механизмы масштабирования и повышения надежности в распределенных системах.

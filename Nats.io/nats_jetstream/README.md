# Обучение по использованию nats jetstream

### Описание:
Задача включает обучение работе с NATS JetStream — системой потоковой обработки сообщений в NATS. Изучаются основные функции, такие как создание потоков (streams), публикация и потребление сообщений с поддержкой persistence, а также управление durable-подписками. Это помогает освоить инструмент для построения надежных и масштабируемых систем обработки событий и потоковых данных.


### Задачи:
- Изучить паттерн подписки на группу
- Изучить паттерн "pull_subscribe"
- Изучить паттерн распределение нагрузки

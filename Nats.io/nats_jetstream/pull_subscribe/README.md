### Задача:
* Изучение паттерна "pull_subscribe"

### Описание:
Задача включает изучение паттерна Pull Subscribe, используемого в messaging-системах для потребления сообщений по запросу. Исследуется, как потребитель может явно запрашивать сообщения из топика, что позволяет контролировать скорость обработки и управлять нагрузкой. Это помогает понять подходы к эффективному управлению потоком данных в системах с высокой нагрузкой.

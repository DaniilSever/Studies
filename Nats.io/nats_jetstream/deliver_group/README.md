### Задача:
* Изучение паттерна подписки на группу

### Описание:
Задача включает изучение паттерна подписки на группу (Queue Groups), используемого в messaging-системах для распределения нагрузки между потребителями. Исследуется, как несколько подписчиков в одной группе могут совместно обрабатывать сообщения из одного топика, обеспечивая балансировку и отказоустойчивость. Это помогает понять механизмы масштабирования и повышения надежности в распределенных системах.

### Задача:
* Изучение паттерна распределение нагрузки

### Описание:
Задача включает изучение паттернов распределения нагрузки (Load Balancing) в messaging-системах. Исследуются подходы, такие как использование Queue Groups или Round-Robin, для равномерного распределения задач между потребителями. Это помогает понять, как эффективно масштабировать системы и обеспечивать отказоустойчивость при обработке большого объема данных.

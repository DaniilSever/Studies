# Обучение по использованию Nats.io

### Описание
Задача включает обучение работе с messaging-системой NATS.io. Изучаются основные возможности, такие как публикация и подписка на сообщения (Pub/Sub), использование паттернов Queue Groups и Request-Reply, а также настройка и управление NATS-сервером. Это помогает освоить инструмент для построения высокопроизводительных и масштабируемых распределенных систем.


### Задачи
- Изучить работу с nats core
- Изучить работу с nats jetstream
